One upload, five stages of validation

Every file that comes through the workspace moves through the same pipeline, in the same order — nothing is skipped, and every stage leaves an artifact behind for you to inspect.

Stage 1

Upload

A new workspace is created and your file is stored as spec.json.

Stage 2

Parse

Structure is extracted and normalized into parsed.json.

Stage 3

Rule Engine

Deterministic checks run first, written to rule_engine.json.

Stage 4

AI Analysis

Gemini reviews what the rule engine can't, saved to ai_analysis.json.

Stage 5

Report

Findings are compiled into report.pdf and .xlsx.

Every stage is inspectable

Each workspace keeps its own JSON artifact per stage, so you can see exactly what changed and when.

Rules before AI

Deterministic checks run first — the model is only asked to reason about what rules alone can't catch.

Two report formats

Every run produces both a shareable PDF and a spreadsheet you can filter, sort, or hand off.
