Systems checklist

One upload, four instrumented stages

Every file that comes through the workspace moves through the same checklist, in the same order — nothing is skipped, and every stage leaves an artifact behind for you to inspect.

STG‑01

Parse

Your spec is validated and normalized into parsed.json.

STG‑02

Rule Engine

Deterministic checks run — default checklist, or your own custom rules JSON — written to rule_engine.json.

STG‑03

AI Analysis

Groq (or Gemini as fallback) reviews what the rule engine can't, saved to ai_analysis.json.

STG‑04

Report

Findings are compiled into report.pdf and .xlsx.

01

Every stage is inspectable

Each workspace keeps its own JSON artifact per stage, so you can see exactly what changed and when.

02

Rules before AI

Deterministic checks run first — the model is only asked to reason about what rules alone can't catch.

03

Two report formats

Every run produces both a shareable PDF and a spreadsheet you can filter, sort, or hand off.
